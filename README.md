# Marketing Website

A modern 5-page marketing website built with HTML, Tailwind CSS, and JavaScript.

## Pages

1. **Home Page** - Features a hero section, services overview, features, testimonials, and a subscription form.
2. **Services Page** - Detailed information about all services offered.
3. **Portfolio Page** - Showcase of previous work with filtering capability.
4. **About Page** - Company information, team members, mission, vision, and values.
5. **Contact Page** - Contact form, location information, and FAQ section.

## Features

- Responsive design that works on all devices
- Modern UI with Tailwind CSS
- Interactive elements with JavaScript
- Optimized for performance and SEO
- Clean, maintainable code structure

## Technologies Used

- HTML5
- CSS3 (Tailwind CSS framework)
- JavaScript (Vanilla JS)
- Font Awesome for icons

## Project Structure

```
├── index.html           # Home page
├── services.html        # Services page
├── portfolio.html       # Portfolio page
├── about.html           # About page
├── contact.html         # Contact page
├── css/
│   └── styles.css       # Custom CSS styles
├── js/
│   └── main.js          # JavaScript functionality
└── images/              # Image assets
```

## Setup Instructions

1. Clone or download this repository
2. Open any HTML file in a web browser to view the website
3. No build process required - this is a static website

## Customization

- Replace placeholder images in the `images` directory with your own
- Update text content in HTML files to match your business information
- Modify colors and styling in `css/styles.css` to match your brand
- Extend JavaScript functionality in `js/main.js` as needed
